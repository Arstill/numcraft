# Как дорабатывать

1. Режимы, станок, инструмент — сначала через YAML в `src/numcraft/knowledge/`, без правки кода.
2. Новое правило технолога: признак → `planner.py`, предупреждение → `risks.py`, стратегия → `strategies.py`.
3. На каждое изменение — тест в `tests/` (`python -m pytest tests`).
4. Числа в техкарте выдаёт только детерминированный код. LLM не назначает режимы.
5. Комментарии в G-коде — латиницей в верхнем регистре: FANUC не выводит кириллицу.
