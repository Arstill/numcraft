# NumCraft — помощник технолога-фрезеровщика

Получает описание детали, чертёж или STEP-модель и выдаёт **техкарту** под конкретный цех:

- **Станок:** Haas VF-2 (FANUC-совместимая стойка Haas NGC), шпиндель 8100 об/мин CT40 (опция 12000)
- **CAM:** SolidWorks + HSMWorks. Траектории строит HSMWorks, NumCraft подсказывает стратегию и параметры
- **Материалы:** алюминий 6061-T6, 7075-T6; сталь 45 (ГОСТ 1050), AISI 1045
- **Детали:** 2.5D–3-осевые

Что содержит техкарта:

1. Установы и крепление (тиски, захват, параллели, переворот) и нуль G54/G55.
2. Порядок операций: торцовка → черновая (Adaptive) → центровка → сверление → чистовая → фаски → резьба → развёртка.
3. Инструмент: T/H/D, вылет, библиотека цеха в YAML.
4. Режимы под VF-2: n и F с учётом предела оборотов и подачи станка, утонения стружки, мощности по кривой момента шпинделя.
5. Стратегии HSMWorks и значения полей: Optimal load, Maximum stepdown, Stock to leave, Ramp, Cycle type, Pecking depth…
6. Риски: тонкие стенки и дно, вылет, глубокие отверстия, метчики в стали, коробление 7075, ходы станка, захват.
7. Черновик УП FANUC или Haas: шапка, смены инструмента, торцовка и циклы G81/G73/G83/G84/G85 по координатам. Места для фрезерных траекторий из HSMWorks отмечены.

Все числа считает детерминированный код (`src/numcraft`). LLM необязательна: она только помогает разобрать свободный текст или скан и даёт комментарий технолога.

## Быстрый старт: перетащить файлы

1. Установить Python 3.12+ с python.org и в первом окне установщика отметить «Add python.exe to PATH». Библиотеки `numcraft.bat` поставит сам при первом запуске (вручную: `py -m pip install pydantic pyyaml pypdf`).
2. Перетащить на **`numcraft.bat`** (корень проекта) STEP-модель и PDF чертежа детали, можно оба сразу.
3. Техкарта откроется в браузере. Рядом с моделью появятся файлы `<деталь>_техкарта.html`, `<деталь>_техкарта.md` и черновик УП `<деталь>.nc`.

Что откуда берётся:

- **STEP** — геометрия: габарит, отверстия, карманы, радиусы.
- **PDF** (экспорт из SolidWorks, с текстом) — материал из штампа, квалитеты, резьбы, Ra, общие допуски.
- Если материала в PDF нет, программа спросит его в окне.
- Один PDF без STEP геометрию не даёт: нужна модель.

## Командная строка

```bash
cd src
python -m numcraft plan "Кронштейн 120х80х20, алюминий 6061. Карман 60х40 глубина 8 R5 в центре. \
4 отв. Ø6.6 сквозные по углам с отступом 10. 2 резьбы М6 гл. 12 в точках (30, 40), (90, 40). \
Отверстие Ø10H7 сквозное в центре. Фаска 0.5 по контуру." --gcode -o techsheet.md
```

Ещё варианты:

```bash
python -m numcraft plan --step part.step --drawing part.pdf --material 7075 -o techsheet.md --nc part.nc
python -m numcraft plan --json ../examples/flanets_st45.json --gcode --dialect haas
python -m numcraft step part.step                       # что видно в модели
python -m numcraft drawing part.pdf                     # обозначения с чертежа
python -m numcraft cut --material "сталь 45" --d 10 --op adaptive    # режим для одной фрезы
python -m numcraft plan --rpm 12000 ...                 # шпиндель 12k
```

Готовые примеры результата: `examples/*_techsheet.md`, `examples/kronshtein_6061.nc`.

Зависимости ядра: Python ≥ 3.12, `pydantic`, `PyYAML`, `pypdf` (для PDF). Граф и агент дополнительно требуют `langgraph` и `langchain`.

## Что понимает разбор описания

| Элемент | Пример |
|---|---|
| Габарит / заготовка | `Плита 120х80х20`, `заготовка 126х86х30` |
| Материал | `6061`, `7075-T6`, `В95`, `сталь 45`, `C45`, `AISI 1045` |
| Карман / окно | `карман 60х40 гл. 8 R5 в центре`, `окно сквозное 80x30 R6` |
| Паз | `паз 30x8 глубиной 5` |
| Отверстия | `4 отв. Ø6.6 сквозные по углам с отступом 10`, `Ø10H7`, `Ø9 с цековкой Ø15 гл 9` |
| Резьбы | `2 резьбы М6 гл. 12`, `6xM5 гл.10`, `M8x1 снизу X50 Y50` |
| Координаты | `(30, 40)`, `X50 Y50`, `по углам 12`, `в центре` |
| Фаски, 3D | `фаска 0.5 по контуру`, `3D поверхность R3 Ra 1.6` |
| Прочее | `снизу` (установ 2), `ISO 2768-m`, `партия 20 шт.` |

Система координат детали: **X0 Y0 — левый передний угол, вид сверху; Z0 — верх готовой детали.** Элементы снизу задаются в тех же координатах вида сверху, переворот вокруг X планировщик учтёт сам.

Неполные данные не угадываются молча: в техкарте появляется раздел «Вопросы к чертежу», а CLI возвращает код 2 со списком недостающего.

## STEP и чертёж

- **STEP (AP203/214/242)** разбирается без OpenCascade. Извлекаются габарит, отверстия (сквозное или глухое, цековки, отверстия в дне кармана), полы карманов и уступов, внутренние радиусы, признаки 3D-поверхностей и направления обработки. Резьбы геометрия не показывает: отверстия Ø5.0, Ø6.8 и т.п. помечаются как «возможно резьба».
- **Чертёж** (PDF с текстовым слоем, DXF, TXT): материал, квалитеты (Ø10H7), резьбы, Ra, общие допуски. Применяется поверх STEP: квалитеты ставятся на отверстия, отверстия под метчик превращаются в резьбы. Сканы (PNG/JPG) разбираются только через LLM (`use_llm`).

## Настройка под цех

| Файл | Что править |
|---|---|
| `src/numcraft/knowledge/machine_haas_vf2.yaml` | обороты, мощность и момент, ходы, тиски |
| `src/numcraft/knowledge/tool_library.yaml` | фактический набор фрез: D, z, Lc, вылет |
| `src/numcraft/knowledge/materials.yaml` | стартовые Vc, fz, ae, ap, припуски, угол врезания |

## Архитектура

```
src/numcraft/
  models.py            схема Part (вход) и TechSheet (выход), pydantic
  knowledge/           станок, материалы, библиотека инструмента (YAML)
  cutting.py           режимы резания с ограничениями VF-2
  strategies.py        стратегии HSMWorks и их параметры
  planner.py           установы, порядок операций, выбор инструмента
  risks.py             правила рисков
  gcode.py             черновик УП FANUC / Haas NGC
  techsheet.py         Markdown / JSON
  parsers/text.py      русское описание → Part
  parsers/step.py      STEP → геометрия → Part
  parsers/drawing.py   PDF/DXF → обозначения
  pipeline.py          объединение источников
  llm.py               (опц.) извлечение Part и рецензия через LLM
  cli.py               командная строка
src/graphs/graph.py    LangGraph: intake → [llm_extract] → plan → [review] → render
src/agents/agent.py    чат-агент «Технолог» с инструментами plan_part / analyze_step / analyze_drawing / cutting_data
src/main.py            HTTP-сервис платформы Coze (/run, /stream_run, /v1/chat/completions)
```

План изменений и приоритеты описаны в [docs/PLAN.md](docs/PLAN.md).

## Ограничения MVP

- Траектории, симуляция и проверка столкновений остаются в HSMWorks: G-код здесь только черновик.
- Через карманы и пазы STEP-разбор пока не определяет; признаки из STEP нужно проверять.
- Режимы — стартовые значения для твёрдосплавного инструмента. Первую деталь вести с коррекцией подачи 70–80 %.
