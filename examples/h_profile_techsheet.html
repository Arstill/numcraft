Допущения

  • Деталь развёрнута для обработки: верх — сторона +Y модели (габарит 20 мм — толщина), вдоль X станка — ось X модели (40 мм).
  • Ø3.4 длиной 40 мм проходит через 2 стенки (материал 3+3 мм, между ними пустота): удлинённым сверлом с одной стороны — один установ; коротким — с двух сторон, +1 установ.
  • Элементы по сторонам: сверху, снизу, спереди.
  • Заготовка не задана — принята пиленая плита 46×46×30 мм (+3 мм на сторону по XY, по Z: 1 мм под торцовку сверху + зона захвата в тисках снизу).
  • Наружный контур (габарит детали) обрабатывается из заготовки.

Установ 1 — верх (сторона A)

Крепление:

  • Тиски 6" (Kurt DX6 / Haas): зажим по стороне 46 мм, захват 5 мм по высоте, заготовка на параллелях; над губками ≈ 25 мм.
  • Губки рифлёные или гладкие стальные; заготовку осадить на параллели (киянкой), проверить щупом 0.02 мм.

Нуль детали:

  • G54: X0 Y0 — центр заготовки: ощупать заготовку щупом с двух сторон по X и по Y
  • Z0 — верх заготовки (касание фрезой/щупом). Торцовка снимает 1 мм — верх детали будет на Z−1; все глубины в таблицах — от этого Z0.
  • HSMWorks: Setup → Work Coordinate System — Stock box point, «Top center» (верх, центр)

Установ 2 — низ (сторона B, переворот)

Крепление:

  • Переворот вокруг оси X (передняя грань уходит назад).
  • Тиски 6" (Kurt DX6 / Haas): зажим по обработанным боковым граням, гладкие или мягкие губки; под обработанный верх — чистые параллели.
  • Параллели — под сплошные участки верха (стенки), не под паз/карман F4: иначе деталь прогнётся при торцовке.
  • Захват ≥ 3 мм; деталь выступает над губками на 11 мм и больше (торцовка не должна задеть губки).

Нуль детали:

  • G55: X0 Y0 — центр детали по обработанному контуру (щуп по двум парам сторон)
  • Z0 — низ детали (готовый размер по толщине 20 мм): деталь на параллелях, Z0 = верх параллелей + 20 мм; необработанная поверхность сейчас выше на 9 мм — её снимает торцовка.
  • HSMWorks: новый Setup с переворотом (Orientation: Z — вниз по модели), WCS — Model box point «Top center»

Установ 3 — передняя грань

Крепление:

  • Деталь на бок, передняя грань вверх: зажим по верхней и нижней плоскостям (обработаны), губки по 20 мм, длина в губках 40 мм.
  • Деталь стоит на параллелях гранью «задняя грань»; в губках ≥ 20 мм (половина высоты), над губками 5–10 мм — элементы уходят внутрь детали, губки не мешают.
  • Упор по обработанной грани; перпендикулярность базы проверить индикатором ≤ 0.02 мм.

Нуль детали:

  • G56: X0 Y0 — центр грани «передняя грань» (вид на грань: X вдоль грани 40 мм, Y по высоте 20 мм).
  • Z0 — плоскость грани (обработана, касание щупом).
  • HSMWorks: новый Setup, ось Z — по нормали к этой грани, WCS — Model box point «Top center».
